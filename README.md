MediCore Hospital Management System

Full-featured SFML GUI based Hospital Management System for OOP Course.

Features
- Professional SFML Graphical User Interface
- Three Roles: Patient, Doctor, Admin
- Appointment Booking & Management
- Prescription System
- Billing & Payment
- Admin Dashboard with Reports
